🗳️ Online Voting System using PHP and MySQL
📖 Project Description

The Online Voting System is a web-based application developed using PHP and MySQL, designed to conduct digital elections securely and efficiently. This system aims to replace the traditional paper-based voting method by introducing an automated, transparent, and user-friendly platform. It ensures data integrity, prevents unauthorized access, and simplifies the overall election management process.

🎯 Objectives

Develop a secure and efficient online voting platform.
Ensure transparency and eliminate duplicate or unauthorized voting.
Automate vote counting and result generation.
Provide administrative control for managing candidates and voters.

🌐 Scope of the Project

This application is suitable for colleges, universities, organizations, and small institutions to conduct internal elections. It allows administrators to manage candidates and monitor election progress, while voters can easily register and cast their votes online from any device connected to the network.

⚙️ System Features

🔐 User Registration and Authentication – Only authorized users can access the voting system.
🧑‍💼 Admin Dashboard – Manage elections, candidates, and voters efficiently.
🗳️ Voter Panel – Allows registered users to cast votes securely.
📊 Real-Time Vote Counting – Automatically displays live results.
🛡️ Data Security – Prevents double voting and ensures database confidentiality.

💻 Technologies Used
Component	Technology
Frontend	: HTML5, CSS3, JavaScript
Backend	: PHP
Database	: MySQL
Server Environment	: XAMPP / WAMP

🧩 Installation Steps

Download or clone this repository.
Move the project folder to the htdocs directory in XAMPP.
Import the provided .sql file into phpMyAdmin.
Update database credentials in the config.php file.
Start Apache and MySQL from XAMPP Control Panel.

Open your web browser and navigate to:
http://localhost/votingsystem/
